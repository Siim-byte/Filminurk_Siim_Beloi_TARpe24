# 🎬 Filminurk

Veebirakendus, kus kasutajad saavad sirvida filmide valikut, neid osta ning lisada oma arvustusi ja hinnanguid. Loodud kooliprojektina Tallinna Tehnoloogiakolledžis (TARpe24), keskendudes rakenduse funktsionaalsusele ja äriloogikale.

## 🚀 Peamised funktsioonid
* **Filmide kataloog:** Filmide kuvamine ja detailvaade (žanr, kirjeldus, hind).
* **Kasutajate arvustused:** Kasutajad saavad filmidele hinnanguid ja kommentaare lisada.
* **Ostukorv ja ostmine:** Filmide lisamine ostukorvi ja ostu vormistamine.
* **Haldusvaade (CRUD):** Uute filmide lisamine, muutmine ja kustutamine andmebaasist.

## 🛠️ Kasutatud tehnoloogiad
* **Keel ja raamistik:** C# / ASP.NET Core (MVC ja Razor Pages)
* **Andmebaas:** SQL Server / Entity Framework Core
* **Kasutajaliides:** HTML5, CSS3 (funktsionaalne baasvaade)

## ⚙️ Käivitamine
1. Klooni repositoorium:
   ```bash
   git clone https://github.com
   ```
2. Ava `.sln` fail Visual Studios.
3. Kontrolli andmebaasi ühenduse stringi (`appsettings.json`) ja käivita migratsioonid (`Update-Database` Package Manager Console'is).
4. Käivita projekt (`F5`).
